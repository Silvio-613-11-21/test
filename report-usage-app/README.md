## Пересборка

```bash
pip install python-docx pillow
python3 build_report.py     # читает img/, пишет .docx рядом
```

`build_report.py` повторяет оформление примера: Title по центру, таблицы с залитым
заголовком, подписи рисунков курсивом 9,5 пт, номер страницы в нижнем колонтитуле
(поле PAGE, 9 пт, серый). Номера рисунков заданы в `FIG` и сверяются при вставке —
при перестановке блоков сборка упадёт, а не напечатает неверную ссылку.
