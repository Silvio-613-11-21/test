# Анализ внешней среды — онлайн-эмулятор ассемблера (AsmEmu)

Отчёт по шаблону приложения **ExtEnvAnalysis** (`Silvio-613-11-21/test2` →
`ExtEnvAnalysis_Report_20261101_184218.pdf`) с осмысленными данными по теме
**«Разработка онлайн-эмулятора языка ассемблера для поддержки учебного процесса в вузе»**.

Готовый документ: **`out/ExtEnvAnalysis_Report_ASM.pdf`** (48 страниц, A4, Lato,
та же структура, что и у отчёта программы).

## Что заполнено в приложении (вкладки 1–7)

| Вкладка | Содержание |
|---|---|
| 1. Сегмент | Разработка программного обеспечения |
| 2. PESTEL | 30 факторов (6 категорий × 5), например «Требования Минобрнауки к электронным образовательным ресурсам (5/5)» |
| 3. Факторы и веса | 10 факторов, сумма весов = 1,00 (функциональная полнота команд 0,15 … масштабируемость 0,06) |
| 4. Оценка компаний | AsmEmu (наш проект), MARS 4.5, emu8086, RARS 1.6; доли рынка 14 / 33 / 28 / 25 % |
| 5. Карты сравнения | 45 стратегических карт (C(10,2)); у каждой — своё «направление развития» |
| 6. Итоги | Заключение с выводами и дорожной картой |
| 7. Отчёт | PDF |

## Итоговые показатели (как считает `RatingCalculationService.cs`)

взвешенный рейтинг = Σ(вес × оценка), шкала 0–10:

| Компания | Доля рынка | Рейтинг |
|---|---|---|
| AsmEmu (наш проект) | 14,0 % | **8,50** |
| MARS 4.5 | 33,0 % | 5,46 |
| emu8086 | 28,0 % | 4,05 |
| RARS 1.6 | 25,0 % | 4,97 |

Сильные стороны проекта — всё, что критично для вуза: работа из браузера без
установки (10/10), русскоязычный интерфейс (10), соответствие ФГОС (9), данные в
РФ по ФЗ-152 (9), интеграция с LMS и автопроверка (8). Слабые — полнота набора
команд (7), техподдержка (6), масштабируемость (7); при их устранении рейтинг
растёт до 8,92.

## Данные и воспроизведение

* `data/asm_emulator_env.json` — все введённые значения (PESTEL, факторы, веса,
  оценки, доли рынка, заключение, тема).
* `simulate_extenv.py` — воспроизводит шаги приложения и собирает PDF в той же
  вёрстке, что `Services/ReportBuilder.cs` + `Controls/StrategyMap.xaml.cs`
  (поля 30 pt, Lato 11 pt, шапка 18 pt, колонтитул «Стр. N / M», сетка 10×10,
  размер круга пропорционален доле рынка, цвета компаний #2196F3 / #FF9800 /
  #78909C / #9C27B0).

```bash
pip install pymupdf
python3 simulate_extenv.py --verbose --out out/ExtEnvAnalysis_Report_ASM.pdf
```

`fonts/` — Lato (SIL Open Font License, `fonts/OFL.txt`), тот же шрифт, что
использует отчёт программы.
